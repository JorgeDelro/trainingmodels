**Status: early development. The package is not yet usable.** It currently
contains only the repository skeleton; no models are implemented.

`trainingmodels` will provide mathematical models of training load and
training response used in sport science: descriptors of daily training load
and impulse-response models (starting with the Banister model). A Shiny app
for teaching will be added later.

Design decisions are recorded in [DECISIONS.md](DECISIONS.md) and the use of
AI assistance is disclosed in [AI_USAGE.md](AI_USAGE.md).

## Installation

Not yet recommended. The development version will be installable with:

```r
# install.packages("pak")
pak::pak("JorgeDelro/trainingmodels")
```
